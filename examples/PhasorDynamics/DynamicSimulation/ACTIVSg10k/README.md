# ACTIVSg10k Steady State

This example runs the reusable
[ACTIVSg10k case](../../../../cases/PhasorDynamics/ACTIVSg10k/README.md)
for 0.05 seconds without disturbances.

`ACTIVSg10k.plot.solver.json` is a ten-second bus-fault study that writes bus
monitor data and an IDA internal-step trace for the shared PhasorDynamics
plotting scripts.
