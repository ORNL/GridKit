# ACTIVSg10k

This example uses the reusable
[ACTIVSg10k case](../../../../cases/PhasorDynamics/ACTIVSg10k).

`ACTIVSg10k.solver.json` is the short CTest study.
`ACTIVSg10k.plot.solver.json` is a ten-second bus-fault study that writes bus
monitor data and an IDA internal-step trace for the shared PhasorDynamics
plotting scripts.
