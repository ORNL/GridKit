# Bus Model

The bus hierarchy contains two high-level bus types, electrical and control. 
Electrical buses represent actual electrical nodes which are used in circuit 
analysis. Control buses represent control signals/channels which 
represent communication between two component models.

## Bus Types

- Electric Bus (See [BusElectric](./BusElectric/))
  - Network Bus 
  - Infinite Bus
- Control Bus(See [BusControl](./BusControl/))
  - Signal Bus
