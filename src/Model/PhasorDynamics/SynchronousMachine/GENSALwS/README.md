## Simplifications
The GENSAL model is a variation of the [General Synchronous Machine Model](../README.md)
- $`X''_{q}=X''_{d}`$
- $`X''_{d}`$ does not saturate
- Only d-axis affected by saturation
- $`X_{q}=X'_{q}`$
- $T'_{q0}$ is neglected
