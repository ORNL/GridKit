# Reference Frame Operators

Reference frame operators transform real, instantaneous three-component
signals. Clarke and Park use power-invariant normalization. Each operator
supports the inverse transformation through the `inverse` parameter.

## Models

- [Clarke](Clarke/README.md): $abc$ to $\alpha\beta0$.
- [Park](Park/README.md): $abc$ to $dq0$.
- [Rotation](Rotation/README.md): $\alpha\beta0$ to $dq0$.
