# Branch

A branch is a standard $\pi$ section with total shunt admittance `G + jB` and
a fixed from-side tap $T=\tau e^{\mathrm j\phi}$. It contributes terminal
powers leaving both buses; `open` makes both contributions zero.

When `smax` is present, both terminal apparent powers satisfy

$$|S_{\ell i}|^2,\ |S_{\ell j}|^2\le(s_\ell^{max})^2.$$

See the [system formulation](../README.md#formulation) for the admittance
matrix and sign convention.
