# Stabilizer Models

Stabilizers damp machine oscillations. IEEEST is implemented; PSS1A and PSS2A remain specification drafts.

## Types

- [IEEEST](IEEEST/README.md): IEEE stabilizer
- [PSS1A](PSS1A/README.md): Single-input power system stabilizer
- [PSS2A](PSS2A/README.md): Dual-input power system stabilizer
