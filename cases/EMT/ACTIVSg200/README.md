# ACTIVSg200

Synthetic Illinois, 60 Hz balanced three-phase EMT. 200 AC buses, 180 lines, 66 transformers and 40 synchronous machines.

## Development

The [state](./ACTIVSg200.state.json) gives the initial operating point. The case is
used by the [ACTIVSg200 validation study](../../../examples/EMT/Validation/ACTIVSg200/README.md).
